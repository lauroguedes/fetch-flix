# V1

## Relax the contract, never tighten it
This is a versioned public API with a shipped consumer. Turning a field from
`required` to `sometimes` is backward compatible and needs no new version;
the reverse breaks live clients and does.
`url` is the only required field on /resolve. Everything else has a default.
Pair `sometimes` with `nullable` on any optional field a client might send
explicitly nulled rather than omit — `sometimes` alone only skips an *absent*
key, and a client mid-migration nulls the key it is abandoning.
`prefer` is optional but still validated against `Rule::in(['progressive'])`
rather than ignored: asking for `adaptive` must be a 422, not a silent
fallback, so adding that mode later stays additive.
